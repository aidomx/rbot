# Security Policy

## Supported Versions
Currently, only the latest release of `rbot` is supported with security updates.

## Reporting a Vulnerability
Because `rbot` is a build system that executes shell commands based on `Buildfile` configurations, please ensure you only run `rbot` on trusted codebases. 

If you discover a security vulnerability within `rbot` itself (e.g., in its C core parsing logic), please send an email to [your-email-or-github-alias] with the subject "rbot Security Vulnerability". 

We will respond within 48 hours to acknowledge the report and work on a fix.
